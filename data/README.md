# Data

## Where the data goes

Put the files supplied by the lecturer (downloaded from Canvas) into `data/raw/`, exactly as they were downloaded.

## Rules for data/raw/

- **Never edit, rename or delete** anything in `data/raw/`. These files are our untouched source of truth.
- All cleaning happens in code (`src/etl/`), so anyone can re-run the pipeline and get the same result.
- The files are not saved to Git (see `.gitignore`) until the tutor confirms we may commit them.
